# 牛马鼓励器 🐴🥕

> 把工资按秒磨出来，再让一头驴替你跑完这场马拉松。

一个带互动的实时工资计算器：左边是精确到小数点后四位的进账数字，右边是一头围着磨盘转圈的驴。头顶的杆子挂着胡萝卜，驴永远差一点就吃到。

灵感来自 [realtime-salary](https://github.com/Mereithhh/realtime-salary)，重做了 UI，并加入了完整的驴拉磨动画互动区。

## ✨ 有什么

- **实时工资**：按秒结算，支持年薪 / 月薪 / 周薪 / 时薪，自定义每天工时与年节假日天数。
- **拉磨动画**：驴绕着磨盘转圈，磨盘跟着转，胡萝卜在眼前晃。驴腿、尾巴、耳朵、胡萝卜都有独立动画。
- **听歌**：切到驴戴耳机的正面头像，摸鱼 FM 开始播放《胡萝卜的诱惑》，音符飘起来。
- **玩手机**：驴抱起手机刷短视频，眼睛盯着屏幕，旁边飘着「老板：在吗？」和 99+ 未读消息。
- **上厕所**：驴一路狂奔冲进茅房，带薪如厕倒计时结束后自动回来继续拉磨。
- **鞭策**：抽两下，画面出现「啪！」和驴的抽搐，磨速提升一档（最高 3.1 倍），转圈和迈腿一起加速。
- **画大饼**：老板在驴头顶画一张会发光的饼，配一句「明年给你涨薪」之类的空头支票；驴更来劲了，磨速同样加快。
- **牛马小票**：今日回本进度、已拉磨圈数、已鞭策次数、磨速倍率、年化总包，一应俱全。
- 窗口无边框，可拖动、置顶、最小化；数据只存在本地。

## 🛠 开发

```bash
npm install

# 浏览器里开发 UI
npm run dev

# Electron 窗口里开发
npm run electron:dev
```

## 📦 打包 exe

```bash
npm run dist
```

输出在 `release/` 目录，文件名形如 `牛马鼓励器-1.0.0.exe`，是免安装的便携版 exe，双击即用。

当前已打好的一版就在：

```
release/牛马鼓励器-1.0.0.exe
```

> 这个 exe 没做代码签名，Windows 首次运行时可能提示「未知发布者」。点「更多信息 → 仍要运行」即可，不影响功能。

## 🎮 怎么玩

1. 第一次打开：填薪资、周期、每天工时和节假日，点「套上磨，开转」。
2. 默认画面：驴绕磨盘转圈，头顶杆子挂着胡萝卜，左边数字按秒进账。
3. **听歌**：换成驴戴耳机的正面头像，进入摸鱼 FM；再点「收工」回去拉磨。
4. **玩手机**：驴抱起手机刷短视频，旁边冒出老板的消息和 99+ 未读；点「收手机」回去拉磨。
5. **上厕所**：驴一路小跑冲进茅房，带薪倒计时结束后自动回来。
6. **鞭策**：每次抽两下，画面弹「啪！」、驴会抖一下，磨速 +30%，最高 3.1 倍，转圈和迈腿一起变快。
7. **画大饼**：每次画一张带笑脸的饼，配一句老板语录，磨速 +25%；和鞭策共用速度上限。
8. 「重新设置」可以改工资；设置会存在本地，下次打开直接进入计时。

## 📐 计算口径

- 先算出一年里真正需要上班的小时数：`(365 - 节假日天数) × 每天工时`
- 再把薪资折算到每秒：
  - 年薪 ÷ 全年工作秒数
  - 月薪 ÷（全年工作天数 ÷ 12 × 每天工时 × 3600）
  - 周薪 ÷（全年工作天数 ÷ 52 × 每天工时 × 3600）
  - 时薪 ÷ 3600
- 进账从点击「套上磨，开转」那一刻开始累计，用 `decimal.js` 做高精度计算。

> 摸鱼和上厕所期间工资照涨——毕竟是带薪的。
